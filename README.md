# Overview:
An AI-powered walking tour planner for the city of Edinburgh to reduce decision paralysis for tourists.

# Features:
- Generates personalized travel itineraries based on user preferences such as location, theme, start date, and walking pace.
- Integrates real-time weather and crowd-level data to dynamically optimize tour recommendations.

# Built with:
- React
- TypeScript
- TailwindCSS
- Framer Motion
- React Leaflet
- OpenAI AI SDK
- Vercel AI SDK
- Vite
